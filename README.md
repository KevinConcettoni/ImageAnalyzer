# 👁️ VISIA – Visual Intelligence System for Image Analysis

An intuitive and powerful application for analyzing images using **Artificial Intelligence models**.  
Developed as part of an internship project at the **University of Camerino**.  

---

## 🚀 What is VISIA?  
VISIA is a platform designed to make **image analysis with AI simple and accessible**.  
With just a few clicks you can:  
- 📂 Upload single images or entire folders  
- 🤖 Choose from built-in or custom AI models  
- 🔎 Visualize results with **bounding boxes** and predictions  
- 💾 Save, reload, and manage your analyses with ease  

---

## 🛠️ Main Features  

- **📂 Image Upload**  
  - Import single images or full folders directly from your device.  

- **🤖 AI Model Management**  
  - Select a model from a dropdown menu (including a default text analysis model).  
  - Upload new custom models (`.keras` or `.h5`) with an accompanying `.json` file for class labels.  
  - Remove uploaded models (default model cannot be deleted).  

- **🔎 Image Analysis**  
  - Run analysis on one or multiple images and extract insights from the selected model.  
  - Visualize bounding boxes and predictions in real time.  

- **💾 Results Management**  
  - Download results: annotated image + JSON file containing predictions and model information.  
  - Reload previously saved results at any time.  

- **🖥️ Interactive Interface**  
  - Sidebar with a list of imported images always visible.  
  - Quick preview and full-size image view.  
  - **Reset button** to clear the interface and start fresh.
